Bare Bones Mail

A small Gmail client. To connect to your Google account you need a free OAuth Client ID (one-time setup):

  1. Go to Google Cloud Console and create a project.
  2. Enable the Gmail API (APIs & Services → Library).
  3. OAuth consent screen: choose External, fill in the basics, and add your Gmail address under Test users.
  4. Credentials → Create credentials → OAuth client ID → type Web application.
  5. Under Authorized JavaScript origins add
  6. Paste the Client ID below.

The Client ID is stored only in this browser. Your mail goes straight between this page and Google.
